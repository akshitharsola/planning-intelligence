# Galway Ingestion CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Galway City and Galway County each a runnable, idempotent, unattended-safe ingestion CLI script that wires the existing `discover → acquire → parse/normalize → resolve_and_upsert → publish` pipeline into one entrypoint, with persisted incremental state so re-runs don't re-process already-ingested data.

**Architecture:** Two standalone scripts (`scripts/ingest_galway_county.py`, `scripts/ingest_galway_city.py`) call existing, unmodified pipeline functions in sequence, wrapped in a per-record/per-row try/except that logs and skips failures rather than aborting the run. A new thin module (`src/core/ingestion_state.py`) backed by two new tables (`ingestion_state`, `ingested_files`) tracks County's `OBJECTID` watermark and City's per-file ingestion status between runs.

**Tech Stack:** Python, SQLAlchemy (sync session via `SessionLocal`), Alembic migrations, pytest, existing `requests`-based scrapers — no new dependencies.

## Global Constraints

- No pipeline stage (`discover`/`acquire`/`extract_planning_table`/`normalize_row`/`normalize_county_row`/`resolve_and_upsert`/`publish`) is modified or reimplemented — call as-is.
- `GalwayCountyScraper.discover()` already reads `self.region_config.get("watermark", 0)` (`src/sources/galway/county/scraper.py:29`) — do not add a new parameter to it. Inject the stored watermark into the `region_config` dict before constructing the scraper.
- Per-record/per-row failures are logged (region + source identifier + exception) and skipped — never fatal to the run.
- County: watermark advances only past the max **successfully-ingested** `OBJECTID`, never past a failed record.
- City: a file is marked ingested only if **every row in it succeeded** — any row failure leaves the whole file unmarked for full retry next run (self-healing, not "mark done regardless").
- Both scripts support `--dry-run`: runs discover/acquire/parse/normalize, prints a summary, skips `resolve_and_upsert`'s commit, `publish`, and all `ingestion_state`/`ingested_files` writes.
- New files: `src/core/ingestion_state.py`, `tests/unit/core/test_ingestion_state.py`, `tests/integration/test_ingest_galway_county.py`, `tests/integration/test_ingest_galway_city.py`, `scripts/ingest_galway_county.py`, `scripts/ingest_galway_city.py`, migration `src/core/db/migrations/versions/0002_create_ingestion_state.py`.
- Migration chains via `down_revision = '0001'`, `revision = '0002'`, matching `0001_create_applications_and_events.py`'s convention exactly (zero-padded 4-digit sequence, manually-named, not Alembic's autogenerated hash).
- **Hard acceptance gate before this feature is considered done:** a live run against the real ArcGIS County endpoint, run twice in sequence, must demonstrate: (1) the second run, using the watermark stored from the first, returns and ingests only genuinely-new records — no re-ingestion of records from the first run; (2) no gap — every record with `OBJECTID` greater than the stored watermark at the time of the second run is fetched; (3) a forced single-record failure during a run does not advance the watermark past that record; (4) run logs clearly report discovered/ingested/failed/skipped counts. This is Task 7 below and cannot be skipped, mocked, or marked done on unit/integration test results alone — per-project decision, this assumption stays a live risk until proven on the real source over real time.

```python
# src/core/ingestion_state.py
"""
Persisted incremental-ingestion state: County's OBJECTID watermark and
City's per-file ingestion tracking, so CLI re-runs don't reprocess
already-ingested data. Backed by ingestion_state and ingested_files
(migration 0002).
"""

from sqlalchemy import text
from sqlalchemy.orm import Session


def get_watermark(session: Session, region: str) -> str | None:
    row = session.execute(
        text("SELECT watermark FROM ingestion_state WHERE region = :region"),
        {"region": region},
    ).first()
    return row[0] if row else None


def set_watermark(session: Session, region: str, watermark: str) -> None:
    session.execute(
        text(
            """
            INSERT INTO ingestion_state (region, watermark, updated_at)
            VALUES (:region, :watermark, now())
            ON CONFLICT (region) DO UPDATE
                SET watermark = EXCLUDED.watermark, updated_at = now()
            """
        ),
        {"region": region, "watermark": watermark},
    )


def is_file_ingested(session: Session, region: str, file_id: str) -> bool:
    row = session.execute(
        text(
            "SELECT 1 FROM ingested_files WHERE region = :region AND file_id = :file_id"
        ),
        {"region": region, "file_id": file_id},
    ).first()
    return row is not None


def mark_file_ingested(session: Session, region: str, file_id: str) -> None:
    session.execute(
        text(
            """
            INSERT INTO ingested_files (region, file_id, ingested_at)
            VALUES (:region, :file_id, now())
            ON CONFLICT (region, file_id) DO NOTHING
            """
        ),
        {"region": region, "file_id": file_id},
    )
```

```python
# scripts/ingest_galway_county.py
"""
Galway County ingestion CLI: discover -> normalize -> resolve -> publish
against the live ArcGIS Feature Service, using a persisted OBJECTID
watermark so re-runs only fetch new records. See
docs/superpowers/specs/2026-06-30-ingestion-cli-design.md section 3.
"""

import argparse
import logging
from pathlib import Path

from src.core.db.session import SessionLocal
from src.core.ingestion_state import get_watermark, set_watermark
from src.core.normalization.galway_county import normalize_county_row
from src.pipelines.discover import load_region_config
from src.pipelines.publish import publish
from src.pipelines.resolve import resolve_and_upsert
from src.sources.galway.county.scraper import GalwayCountyScraper

logger = logging.getLogger(__name__)

REGION = "galway_county"
CONFIG_PATH = Path("config/galway/county.yaml")


def run_county_ingestion(dry_run: bool = False) -> dict:
    session = SessionLocal()
    try:
        stored_watermark = get_watermark(session, REGION)
        region_config = load_region_config(CONFIG_PATH)
        region_config["watermark"] = int(stored_watermark) if stored_watermark else 0

        scraper = GalwayCountyScraper(region_config=region_config, temp_dir=Path("/tmp/unused"))
        records = scraper.discover()

        ingested = 0
        failed = 0
        max_success_objectid = None

        for record in records:
            object_id = record.get("OBJECTID")
            try:
                app_create = normalize_county_row(
                    record, region_config=region_config, source_file="arcgis_feature_service"
                )
                if not dry_run:
                    resolve_and_upsert(session, app_create)
                ingested += 1
                if max_success_objectid is None or object_id > max_success_objectid:
                    max_success_objectid = object_id
            except Exception as exc:
                failed += 1
                logger.error(
                    "Failed to ingest County record region=%s OBJECTID=%s: %s",
                    REGION, object_id, exc,
                )

        new_watermark = str(max_success_objectid) if max_success_objectid is not None else None

        if not dry_run:
            publish(session, region=REGION, rows_ingested=ingested, parse_errors=failed)
            if new_watermark is not None:
                set_watermark(session, REGION, new_watermark)
            session.commit()

        logger.info(
            "County ingestion run complete: discovered=%d ingested=%d failed=%d new_watermark=%s dry_run=%s",
            len(records), ingested, failed, new_watermark, dry_run,
        )

        return {
            "discovered": len(records),
            "ingested": ingested,
            "failed": failed,
            "new_watermark": new_watermark,
        }
    finally:
        session.close()


def main() -> None:
    logging.basicConfig(level=logging.INFO)
    parser = argparse.ArgumentParser(description="Ingest Galway County planning applications.")
    parser.add_argument("--dry-run", action="store_true")
    args = parser.parse_args()

    result = run_county_ingestion(dry_run=args.dry_run)
    print(result)


if __name__ == "__main__":
    main()
```

```python
# scripts/ingest_galway_city.py
"""
Galway City ingestion CLI: discover -> acquire -> parse -> normalize ->
resolve -> publish against the live filegator PDF source, using
per-file ingestion tracking so re-runs skip already-processed PDFs. A
file is only marked ingested once every row in it succeeds (self-healing
retry on partial failure). See
docs/superpowers/specs/2026-06-30-ingestion-cli-design.md section 4.
"""

import argparse
import logging
from pathlib import Path

from src.core.db.session import SessionLocal
from src.core.ingestion_state import is_file_ingested, mark_file_ingested
from src.parsers.pdf_lines.galway_city import extract_planning_table
from src.pipelines.discover import load_region_config
from src.pipelines.normalize import normalize_row
from src.pipelines.publish import publish
from src.pipelines.resolve import resolve_and_upsert
from src.sources.galway.city.scraper import GalwayCityScraper

logger = logging.getLogger(__name__)

REGION = "galway_city"
CONFIG_PATH = Path("config/galway/city.yaml")


def _match_source_type(filename: str) -> str | None:
    region_config = load_region_config(CONFIG_PATH)
    pdf_patterns = region_config["pdf_patterns"]
    lower = filename.lower()
    for source_type, substrings in pdf_patterns.items():
        if any(s in lower for s in substrings):
            return source_type
    return None


def run_city_ingestion(dry_run: bool = False) -> dict:
    session = SessionLocal()
    try:
        region_config = load_region_config(CONFIG_PATH)
        scraper = GalwayCityScraper(region_config=region_config, temp_dir=Path("/tmp/galway_city_ingest"))

        links = scraper.discover()
        skipped = 0
        to_acquire = []
        for link in links:
            if is_file_ingested(session, REGION, link["filename"]):
                skipped += 1
            else:
                to_acquire.append(link)

        ingested = 0
        failed = 0

        if to_acquire:
            local_paths = scraper.acquire(to_acquire)
            for local_path in local_paths:
                source_type = _match_source_type(local_path.name)
                rows = extract_planning_table(local_path, region_config["column_map"])

                file_failed = 0
                for row in rows:
                    try:
                        app_create = normalize_row(
                            row, source_type=source_type or "received",
                            region_config=region_config, source_file=local_path.name,
                        )
                        if not dry_run:
                            resolve_and_upsert(session, app_create)
                        ingested += 1
                    except Exception as exc:
                        failed += 1
                        file_failed += 1
                        logger.error(
                            "Failed to ingest City row region=%s file=%s: %s",
                            REGION, local_path.name, exc,
                        )

                if not dry_run and file_failed == 0:
                    mark_file_ingested(session, REGION, local_path.name)

        if not dry_run:
            publish(session, region=REGION, rows_ingested=ingested, parse_errors=failed)
            session.commit()

        logger.info(
            "City ingestion run complete: discovered=%d skipped_already_ingested=%d "
            "ingested=%d failed=%d dry_run=%s",
            len(links), skipped, ingested, failed, dry_run,
        )

        return {
            "discovered": len(links),
            "skipped_already_ingested": skipped,
            "ingested": ingested,
            "failed": failed,
        }
    finally:
        session.close()


def main() -> None:
    logging.basicConfig(level=logging.INFO)
    parser = argparse.ArgumentParser(description="Ingest Galway City planning applications.")
    parser.add_argument("--dry-run", action="store_true")
    args = parser.parse_args()

    result = run_city_ingestion(dry_run=args.dry_run)
    print(result)


if __name__ == "__main__":
    main()
```
